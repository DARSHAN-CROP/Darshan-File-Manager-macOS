# Changelog

All notable changes to **Darshan File Manager (macOS)** are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0] - 2026-11-05
### Added
- First release for macOS, with the same feature set as Windows 2.0 and Android 2.0.
- **Sort** by type, extension or date (`Year/MM-Month`), with **Undo** for every action.
- **Duplicate finder** (size + SHA-256): moves copies to `Duplicates`, keeps an original, never deletes.
- **Old files cleaner** (30 / 60 / 90 / 180 / 365 / custom days) with preview.
- **Batch rename** with prefix / suffix / find → replace / numbering and preview.
- **My rules**: extension or name contains → folder, applied before the built-in types.
- **Storage usage** bar chart per category.
- **Auto mode** with tick boxes for each action and a summary notification.
- **Themes** (Light / Dark / System) and six accent colours; **English / ગુજરાતી**.
- DarshanCore Swift package with unit tests; GitHub Actions build on macOS.
